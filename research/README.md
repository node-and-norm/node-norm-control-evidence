# Research brief

[Repository](../README.md) / Research

**Can independent reviewers reconstruct the practical force of an AI control from the evidence that survives an event?**

The first study concerns public observability: what a fixed retrieval procedure and coding rule permit a reviewer to establish. Population control effectiveness would require a different evidentiary basis.

> **Status:** contribution hypothesis and development design. No pilot participants, independent empirical ratings, confirmatory estimates, or approved research release.

## Why investigate this

A case narrative can tell a reviewer that a safeguard was described or an intervention occurred. An assurance decision often needs a narrower answer: which control, at which opportunity, under which conditions, with what evidence of downstream action?

CEC proposes a reusable record of those distinctions. Its value could be better-supported reconstruction, clearer identification of evidence that must be preserved, or an empirical demonstration that particular control questions remain unanswerable from public records.

The [literature review](NOVELTY_REVIEW.md) already finds close work on incident uncertainty, accountability coding, audit evidence, and forensics. The defensible candidate contribution is the **tested reconstruction procedure and reusable observations**. An absence of equivalent work has not been established.

## The first empirical deliverable

| Element | Development specification |
| :--- | :--- |
| Unit | Event × control objective × opportunity × relevant period |
| Frame | Publicly documented AI-related events, with declared discovery coverage and source dependence |
| Pilot | Approximately 30 varied events; exploratory definition and feasibility work |
| Main planning target | Approximately 200 events, subject to clustering, precision, capacity, and a frozen frame |
| Candidate primary estimand | Fraction of applicable event-control observations resolving to `yes` or `no` under a fixed packet and rule |
| Mandatory context | All other values, applicability, enumeration coverage, retrieval effort, and event clustering |
| Expected reusable outputs | Evidence inventory, preserved initial judgments, disagreement records, source lineage, versioned codebook and analysis |

The primary weighting, precision target, sample allocation, and acceptance thresholds remain unresolved. [Sampling plan](../docs/methods/SAMPLING_PLAN.md).

## Establish usefulness before scaling

The [comparative pilot](COMPARATIVE_PILOT_DESIGN.md) gives reviewers identical evidence through three representations. An evidence-enrichment experiment is separate because additional retrieval could itself improve observability.

| View | Fair baseline or candidate | Measure |
| :--- | :--- | :--- |
| Narrative with source links | Retains reasonable uncertainty and traceable citations | Supported and unsupported conclusions; unresolved-state retention |
| Simple control checklist | Includes explicit unknown values and citations | Same outcomes; preparation and review time |
| CEC record | Separates source claims, evidence, dimensions, and judgments | Same outcomes; added burden and disagreement |

Independent enumeration comes first. Researchers must retain controls that fail to match across reviewers; agreement among already matched controls is only a conditional result. Known-state controlled examples address criterion validity separately from historical reconstruction.

## Decision gates

| Gate | Evidence needed | Current state |
| :--- | :--- | :--- |
| Novelty | Close-work methods and artifact comparison, independent screening, citation chasing | Open; several access and comparison gaps |
| Feasibility | Rights-reviewed pilot frame, retrieval timing, independent enumeration, workload observations | Unrun |
| Representation value | Balanced comparison, support-scoring manual, predeclared worthwhile difference | Design proposed; decisions unfilled |
| Reliability | Eligible human initial ratings, full disagreement matrices, uncertainty, retained failures | Unrun |
| Construct and criterion validity | External coverage review and separately designed known-state assessment | Unrun |
| Confirmatory study | Frozen protocol and analysis, precision rationale, independent holdout custody | Unfrozen; no sealed holdout |
| Empirical release | Attributable approval, rights, privacy, correction and reproducibility review | Closed in the implementation |

## Results that would change the program

| Observation | Research consequence |
| :--- | :--- |
| A simpler record performs comparably with lower burden | Narrow the representation or justify only the additional function that earns its cost |
| Reviewers disagree about which controls existed as opportunities | Revise enumeration rules; preserve the failed version and avoid a general reliability claim |
| Missingness categories remain confused | Revise the construct boundary and evaluate a new version on new validation data |
| Public packets rarely resolve operation | Report that bounded evidence-availability result with retrieval and selection limitations |
| Equivalent validated infrastructure already exists | Review replication, interoperability, or incremental improvement under the governing change process |

## Who could use the result

| Consumer | Intended use, subject to successful validation |
| :--- | :--- |
| Incident researchers | Reuse a traceable observation and see exactly where inference stops |
| Assurance and audit researchers | Identify documentary support and evidence-preservation requirements |
| Human-oversight researchers | Study authority, intervention conditions, action, and propagation separately |
| TAE, HIT, and RGDS | Consume exact-version empirical records for their own separately justified analyses |

CEC owns its canonical records. Consumers own their interpretations. The [downstream contract](../docs/reference/INTEGRATION_CONTRACT.md) preserves that separation.
