# v0.1.0-dev · Research infrastructure

First tagged development snapshot of the Node & Norm Control Evidence Corpus. **GitHub prerelease; zero independently coded empirical events.**

| Component | What is available |

## Verification and reproduction

The release preparation checks cover all **22 software tests**, schema and example regeneration without drift, local Markdown links and expandable sections, and synthetic export validation. These establish implementation behavior; they do not establish scientific validity.

After downloading all five assets into one directory, check their integrity:

```sh
shasum -a 256 -c SHA256SUMS
```

To reproduce the exports, check out `v0.1.0-dev`, install the pinned dependency, and run:

```sh
python3 -m pip install -r requirements.txt
python3 scripts/export.py examples/synthetic.json --output build/cec-override-unresolved-0.1.0-dev.json
python3 scripts/export.py examples/override-confirmed.json --output build/cec-override-confirmed-0.1.0-dev.json
python3 scripts/export.py examples/policy-only.json --output build/cec-policy-only-0.1.0-dev.json
```

Compare the generated export hashes with `SHA256SUMS`. The manifest identifies the exact source commit and schema version. Checksums detect byte changes; they are not signatures or evidence of independent review.

## Research status

Novelty closure, independent human coding, comparative usefulness, construct validation, holdout custody, and empirical release approval remain open. Source reconnaissance is outside the empirical corpus. The exporter and dossier renderer accept synthetic bundles only. A GitHub release does not advance these scientific gates.

The next research milestone is a staffed, rights-reviewed development pilot. See the [versioned roadmap](https://github.com/node-and-norm/node-norm-control-evidence/blob/v0.1.0-dev/ROADMAP.md), [data statement](https://github.com/node-and-norm/node-norm-control-evidence/blob/v0.1.0-dev/docs/policies/DATA_STATEMENT.md), and [citation metadata](https://github.com/node-and-norm/node-norm-control-evidence/blob/v0.1.0-dev/CITATION.cff).
