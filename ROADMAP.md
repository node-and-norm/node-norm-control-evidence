# Roadmap to a research release

[Repository](README.md) / Roadmap

**Next milestone: a reviewable, staffed development pilot.** This is a sequence of evidence gates. A document's existence does not complete the activity it describes.

| Milestone | Completion evidence | State |
| :--- | :--- | :--- |
| 0 · Inspectable infrastructure | Typed records, runnable examples, integrity checks, readable dossiers, navigation | Implemented for synthetic development |
| 1 · Contribution review | Close-work comparison; independent screening; unresolved access log; explicit contribution decision | Targeted pressure test complete; independent closure pending |
| 2 · Pilot readiness | Rights-reviewed candidate frame, retrieval budget, eligibility records, scoring instruments, assigned independent roles | Workbench prepared; people and decisions pending |
| 3 · Development pilot | About 30 exploratory events; enumeration and label disagreements; comparison with simpler views; burden report | Unrun |
| 4 · Main protocol freeze | Estimand, weighting, precision, acceptance gates, registered analysis, event-family split, holdout custody | Unfrozen |
| 5 · Independent study | Initial ratings, uncertainty and failures, separate adjudication, holdout evaluation | Unrun |
| 6 · Empirical release | Rights and ethics decisions, attributable review, reproducible packages, exact-version citation and archive | Closed |
| 7 · Downstream integration | Audited adapters and site allowlist projection preserving uncertainty and corrections | Contract defined; implementation deferred |
