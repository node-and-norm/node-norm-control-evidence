# Reliability plan: development draft

Core observations used in published conclusions require at least two independent human initial ratings. Eligible coders did not design the frozen method or packet, did not participate in the underlying decision, disclose conflicts and familiarity, and receive no private interpretive coaching. Recruit enough assessors to separate case, coder, and domain effects where feasible.

Freeze codebook, packet hashes, coding interface, eligibility attestations, analysis code, and missingness treatment before coding. Collect independent initial submissions with timestamps and checksums. Adjudication is a subsequent layer. An adjudicator's consensus is never a reliability result.

For every dimension, report n, categorical marginals, exact agreement, the complete disagreement matrix, and a suitable chance-adjusted coefficient with uncertainty where estimable. Treat substantive categories as nominal unless an ordering is justified prospectively. Report unresolved and applicability agreement separately as sensitivity analyses; do not silently remove difficult cases. Resample whole events for clustered intervals. A coefficient with zero marginal variance is undefined and must not be presented as perfect reliability.

Prespecify acceptance thresholds and minimum precision after pilot design work, before main or holdout coding. No numeric general-reliability threshold is asserted here. Low agreement requires ambiguity analysis and an explicit failed gate; amendments create a new method version and new validation data.

TAE's independent-review protocol supplies eligibility and packet safeguards. HIT supplies immutable initial ratings and mandatory failure reporting. HIT's single-case 6-of-7 agreement gate cannot validate this corpus. No human reliability exercise has been performed for CEC.
