# Bounded U.S.-context study: protocol candidate 0.1

Prepared 2 October 2026. Owner: Mark Julius Banasihan. Development only; not frozen or preregistered. No participants, protected operational records, model purchases or external actions are involved.

## Research question

Under specified conditions, does an authorized intervention change execution, and what conclusions can TAE and HIT support from available evidence?

Separate task performance, control performance and assessment performance. Start with synthetic service requests. U.S. context requires declared application assumptions and a versioned framework mapping. Hosting geography alone does not establish it. Formal regulatory participation has not been arranged.

## Method boundaries

TAE retains information access, comprehension capacity, intervention authority, intervention feasibility, exercised judgment and execution propagation. Scripted commands cannot support all six stages. Do not omit required stages to manufacture a supported result. HIT retains its own contract and integrity distinctions; synthetic admissibility remains pending. No method scores are produced by this prototype.

## Test design

Sixteen public development cases currently exercise stop behavior, observation gaps and process recovery. Expected outcomes are authored and share researcher assumptions. The observer reads persisted state independently of acknowledgment, but is not independently developed or reviewed.

The correction-delivery pair and seven retry/restart cases are implemented. Remaining candidates include stale authorization, concurrent requests, interrupted writes and logging loss independent of execution failure. Verify single faults before high-risk combinations. Reserve new scenario families for a frozen study, beyond paraphrases of development cases.

Provide matched task and control baselines. Compare assessment value against a simple checklist using the same admissible evidence. Preserve negative results, disagreements and burden measures. Failure to add value is an admissible result.

## Measures

Report counts and denominators: correct completions / eligible tasks; successful interventions / eligible pre-commit attempts; rejected unauthorized commands / unauthorized attempts; unnecessary blocks / legitimate opportunities. Measure false assurance and appropriate unresolved findings only after assessment and admissibility rules are frozen.

Logical ticks do not measure human decision time. TAE timing margins require all defined timestamps and durations, which this prototype lacks. Separate run errors, behavioral failures and insufficient evidence. Deterministic repeats are reproducibility checks, not independent samples. Later stochastic trials require frozen model versions, prompts, repeat counts, analysis units, uncertainty methods and cost bounds.

## Environment and gates

Current environment is standard-library Python local simulation. SQLite now stores simulated internal and recipient state; a read-only observer queries it after commit. The initial missing-runtime condition was resolved by installing Colima and Docker. The declared container restrictions have been verified; see ENVIRONMENT.md and isolation-runs/isolation-001/. The later environment needs isolated mock services, explicit network restrictions, resource limits, a separate trusted coordinator and no secrets or host-control socket exposed to tested code.

1. Reconcile current remote contracts and synthetic admissibility; preserve original roadmap tasks.
2. Select application, sources, hypotheses, expected outcomes and metrics.
3. Verify execution, outcome observation, fault injection and evidence separation.
4. Independently review where possible; freeze protocol, code/source hashes, analysis, stopping rules and new held-out cases before study runs.
5. Preserve every attempted run and deviation. Stop on unexpected external effects, secret exposure, observer failure or environment drift. Deliberate declared faults remain valid test conditions.
6. Apply each method only under reviewed contracts. Separate researcher outcomes from assessor packets with controlled distribution and opaque assignment.
7. Seek independent reproduction or assessment before claiming either. Report limitations and negative findings.

Technical conformance cannot establish human judgment, field effectiveness, legal compliance, certification or universal safety. Researcher-controlled fixtures and an authored observer remain sources of circularity until challenged independently.
