# Contributing

Start with the Charter, Agenda, Codebook, and Source Policy. Propose a candidate with stable external identifiers, event scope, discovery provenance, rights status, and a primary-source retrieval plan. Preserve incomplete candidates in the availability cohort.

Submit code and data changes with validation output, affected IDs, methodological rationale, AI-use disclosure, and migration implications. Never replace a sealed initial rating. Use a new correction or adjudication object. Do not upload source text without an explicit rights decision.

Run the schema validator and mutation suite before review. Passing tests is necessary for software changes and insufficient for scientific release. Confirmatory labels and reviewer attestations require the actual eligible humans.
